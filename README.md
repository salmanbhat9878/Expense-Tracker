Project Description

Expense Tracker is a Python-based application that helps users manage their income, expenses, and balance.

Features

- Add Income
- Add Expenses
- View Remaining Balance
- Expense Category Selection
- Filter Transactions by Category
- Filter Transactions by Date
- Save Transactions in JSON
- Export Transactions to CSV
- Input Validation
- Interactive Menu System

Technologies Used

- Python
- JSON
- CSV
- datetime
- os

How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the command:

"python expense_traker_final.py"

5. Select an option from the menu.

Menu Options

1. Add Income
2. Add Expense
3. View Balance
4. Filter by Category
5. Filter by Date
6. Export to CSV
7. Exit

Data Storage

Transactions are saved in "transactions.json".

Users can export their transactions to "transactions.csv".
